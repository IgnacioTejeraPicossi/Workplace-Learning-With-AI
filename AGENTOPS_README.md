# AgentOps Orchestrator (n8n Bridge)

## 🚀 Overview

The AgentOps Orchestrator is a powerful module that bridges your AI Learning application with n8n workflows. It allows you to:

- **Start n8n workflows** from your app using webhooks
- **Pass inputs** and receive results back via callbacks
- **Monitor runs**, view logs/outputs, filter/export data
- **Version flows** and manage workflow configurations
- **Use LM Studio** inside n8n for LLM operations

## 🏗️ Architecture

```
[Frontend: AgentOps Orchestrator]
   |  start run + inputs
   v
[FastAPI: agentops router] --(POST)--> [n8n Webhook URL (per workflow)]
   ^                                       |
   |         (POST results / progress)     v
[Callback endpoint] <----------------- [n8n workflow: LM Studio+HTTP nodes]
   |
   v
[Mongo: flows, runs, logs] --> shown in UI (filters/export)
```

## 📋 Prerequisites

1. **n8n running** (Docker is easiest)
   ```bash
   docker run -it --rm --name n8n -p 5678:5678 -v ~/.n8n:/home/node/.n8n n8nio/n8n
   ```

2. **LM Studio running** with OpenAI-compatible API
   - Download from: https://lmstudio.ai/
   - Start with: `http://localhost:1234/v1`

3. **Environment variables**:
   ```bash
   export AGENTOPS_HMAC_SECRET="your-secret-key"
   export MONGO_URI="mongodb://localhost:27017"
   export MONGO_DB="ai_learning_app"
   ```

## 🚀 Usage

### 1. Register a Flow

1. Go to **AgentOps Orchestrator** → **Flow Catalog**
2. Click **Add Flow**
3. Enter:
   - **Flow Name**: e.g., "Web Research Agent"
   - **n8n Webhook URL**: Copy from n8n workflow
   - **Description**: Optional description
4. Click **Add Flow**

### 2. Start a Run

1. Go to **Run Builder**
2. Select a flow from the dropdown
3. Configure input JSON (examples provided)
4. Click **Start Run**
5. Monitor progress in **Runs** tab

### 3. Monitor Runs

1. Go to **Runs** tab
2. Use filters to find specific runs
3. Export data as CSV or JSON
4. View detailed run information

## 📊 API Endpoints

### Flows
- `POST /api/agentops/flows` - Register new flow
- `GET /api/agentops/flows` - List all flows
- `GET /api/agentops/flows/{id}` - Get specific flow
- `PATCH /api/agentops/flows/{id}` - Update flow
- `DELETE /api/agentops/flows/{id}` - Delete flow

### Runs
- `POST /api/agentops/runs/start` - Start new run
- `GET /api/agentops/runs` - List runs with filters
- `GET /api/agentops/runs/{id}` - Get specific run
- `GET /api/agentops/runs/summary` - Get run statistics
- `GET /api/agentops/runs/export` - Export runs data

### Callbacks
- `POST /api/agentops/callback/{flow_id}` - n8n callback endpoint

## 🔐 Security

The module uses HMAC-SHA256 for secure callbacks:

1. Set `AGENTOPS_HMAC_SECRET` environment variable
2. n8n workflows sign requests with this secret
3. Backend verifies signatures before processing

### Testing HMAC

```bash
# Generate signature
echo '{"hello":"world"}' | AGENTOPS_HMAC_SECRET=changeme python scripts/hmac_cli.py sign

# Verify signature
echo '{"hello":"world"}' | AGENTOPS_HMAC_SECRET=changeme python scripts/hmac_cli.py verify --sig abc123...
```

## 🛠️ Troubleshooting

### Common Issues

1. **n8n workflow not responding**
   - Check webhook URL is correct
   - Verify n8n is running and accessible
   - Check workflow is active

2. **HMAC verification failed**
   - Ensure `AGENTOPS_HMAC_SECRET` matches in both places
   - Check n8n workflow is using correct secret
   - Verify callback URL is correct

3. **LM Studio connection failed**
   - Ensure LM Studio is running on correct port
   - Check model is loaded and available
   - Verify API endpoint is accessible

### Debug Mode

Enable debug logging by setting:
```bash
export N8N_TIMEOUT=120
export AGENTOPS_DEBUG=true
```
