# Presentasjonsgenerator (PowerPoint)

Skript som genererer `AI_Learning_with_AI_Presentasjon_Legeforeningen.pptx` i **denne mappen** (samme katalog som `.py`-filen), uavhengig av hvor du kjører kommandoen fra.

## Krav

```bash
pip install python-pptx
```

## Kjøring

Fra prosjektrot:

```bash
python presentation/create_presentation.py
```

eller den enkle varianten:

```bash
python presentation/create_presentation_simple.py
```
